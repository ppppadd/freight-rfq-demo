# FreightGo — 跨境物流智能询价平台（演示版）

> 面向跨境物流商务场景的一站式询报价系统原型，用于展示项目可行性与落地性。
> **本仓库所有价格数据均为虚拟编撰，不含任何真实公司/供应商信息。**

## 一、这是什么

一个解决跨境物流「查价慢、比价难、报价乱」痛点的智能询价系统原型。商务人员只需输入 FBA 仓库代码（如 `ONT8`），系统即可：

- **秒级询价**：返回多家供应商在美线卡派 / 海派 / 欧线三大线路的报价
- **智能比价**：自动按渠道归集、取最低价，给出前三名推荐
- **趋势洞察**：追踪 6 大核心渠道近 4 周价格走势
- **航运周报**：聚合运价指数、市场预测等决策信息

## 三、快速开始

### 方式一：直接演示（推荐）

双击打开 `index.html` 即可，无需任何环境依赖。数据已内嵌，完全离线可用。

### 方式二：重新生成

```bash
# 需要 Python 3.8+，生成脚本依赖开发环境中的模板文件
python3 build_demo.py --template <开发环境模板路径> --output index.html
```

> `build_demo.py` 展示了从「数据源 → 渲染 → 单文件网页」的完整生成链路，
> 与生产系统的 `build.py` 使用同一套模板与注入逻辑，只是数据源换成了虚拟数据。

## 四、演示路径（建议顺序）

1. **首页**：展示平台定位、供应商/仓库/报价规模
2. **搜索 `ONT8`**：查看多家供应商报价，点击比价
3. **切换「欧洲」Tab**：搜索 `DTM2`，展示欧线卡航/海运/铁路报价
4. **排名页**：查看各渠道最优报价前三名
5. **趋势页**：查看 6 大渠道近 4 周价格走势
6. **周报页**：查看 6 类航运决策信息卡片

## 五、技术栈

| 层 | 技术 |
|:---|:---|
| 前端 | 原生 HTML + CSS + JavaScript（响应式，单文件） |
| 图表 | Chart.js（本地内嵌，无 CDN 依赖） |
| 数据生成 | Python（虚拟数据引擎） |
| 生产数据层 | SQLite（三库分离：生产 / 测试 / 档案） |
